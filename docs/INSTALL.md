# راهنمای نصب سامانه انبارداری روی هاست جدید

دو راه برای نصب هست: **روش آسان (نصب‌کنندهٔ وب، مثل وردپرس)** و **روش دستی
(خط فرمان)**. اگر تازه‌کاری، روش اول را برو.

---

## روش آسان — نصب‌کنندهٔ وب (پیشنهادی، مثل نصب وردپرس)

۱. کل پکیج را روی هاست اکسترکت کن و **DocumentRoot دامنه را روی پوشهٔ
   `public/`** بگذار.
۲. از کنترل‌پنل هاست یک **دیتابیس خالی** و یک کاربر دیتابیس بساز (نام دیتابیس،
   نام کاربر و گذرواژه‌اش را یادداشت کن).
۳. در مرورگر **آدرس دامنه یا آی‌پی هاست** را باز کن. چون هنوز نصب نشده،
   خودکار **صفحهٔ نصب** می‌آید.
۴. در صفحهٔ نصب:
   - اطلاعات دیتابیس (میزبان معمولاً `localhost` یا `127.0.0.1`، پورت `3306`،
     نام دیتابیس، کاربر و گذرواژه) را وارد کن.
   - **نام، ایمیل و گذرواژهٔ کاربر مدیر** را بده (همین‌ها یوزر/پسورد اولین
     ورودت هستند).
   - «نصب و راه‌اندازی» را بزن.
۵. سامانه اتصال را تست می‌کند، اطلاعات را در `.env` می‌نویسد، جدول‌ها را
   می‌سازد، انبار پیش‌فرض و کاربر مدیر را ایجاد می‌کند، و **صفحهٔ نصب را قفل
   می‌کند**. بعد از این، هر بار سایت را باز کنی خودِ برنامه می‌آید (نه منوی
   نصب) — دقیقاً مثل وردپرس.

> نکته: پوشه‌های `storage/` و `bootstrap/cache/` باید قابل‌نوشتن باشند
> (`chmod -R 775`) و افزونهٔ PHP به‌نام **`zip`** فعال باشد (برای ورود اکسل).
> اگر خواستی بعداً دوباره نصب کنی، فایل `storage/installed` را پاک کن.

اگر SSH داری و می‌خواهی دستی نصب کنی، ادامه را بخوان.

---

## روش دستی (خط فرمان)

> خلاصهٔ یک‌خطی: کد را بگذار، `.env` را با اطلاعات دیتابیس پر کن، مهاجرت را
> اجرا کن، بعد `php artisan soorin:install` را بزن تا مدیر ساخته شود.

---

## ۱. پیش‌نیازها

- **PHP 8.3 یا بالاتر** با این افزونه‌ها فعال:
  `pdo_mysql`, `mbstring`, `openssl`, `fileinfo`, `ctype`, `json`, `tokenizer`,
  `bcmath`, و **`zip`** (برای ورود فایل اکسل انبار حتماً لازم است).
- **Composer**
- **MySQL 8 یا MariaDB 10.4+**
- دسترسی برای اجرای دستور (SSH). اگر SSH نداری، بخش «هاست اشتراکی بدون SSH»
  را در پایین بخوان.

## ۲. گرفتن کد

```bash
git clone <آدرس-مخزن> soorin-inventory
cd soorin-inventory
composer install --no-dev --optimize-autoloader
```

## ۳. ساخت دیتابیس خالی

از کنترل‌پنل هاست (cPanel/DirectAdmin/phpMyAdmin) یک دیتابیس **خالی** بساز و یک
کاربر دیتابیس با دسترسی کامل به آن. سه چیز را یادداشت کن:
**نام دیتابیس، نام کاربر، گذرواژه**. (روی سرور خودت: `CREATE DATABASE soorin_inventory
CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;`)

## ۴. فایل تنظیمات `.env` — اینجا اطلاعات دیتابیس را می‌دهی

```bash
cp .env.example .env
php artisan key:generate
```

بعد فایل `.env` را باز کن و این‌ها را **درست** پر کن:

```ini
APP_ENV=production
APP_DEBUG=false
APP_URL=http://آدرس-یا-آی‌پی-شما         # مثلاً http://192.168.1.36:8001 یا https://anbar.yoursite.com

# ---- اطلاعات دیتابیس (همان‌هایی که در مرحله ۳ ساختی) ----
DB_CONNECTION=mysql
DB_HOST=127.0.0.1          # روی اغلب هاست‌ها 127.0.0.1 یا localhost
DB_PORT=3306
DB_DATABASE=soorin_inventory   # نام دیتابیسی که ساختی
DB_USERNAME=نام-کاربر-دیتابیس
DB_PASSWORD=گذرواژه-دیتابیس

# ---- روی هاست ساده (بدون Redis) این‌ها را فایل بگذار ----
CACHE_STORE=file
SESSION_DRIVER=file
QUEUE_CONNECTION=sync
```

> نکته: `.env.example` پیش‌فرض برای اجرای Docker است (Redis و DB_HOST=db).
> برای هاست معمولی حتماً `CACHE_STORE` و `SESSION_DRIVER` را `file` بگذار و
> `DB_HOST` را `127.0.0.1` کن. فایل `.env.shared-host.example` نمونهٔ آمادهٔ
> هاست اشتراکی است.

## ۵. ساخت جدول‌ها و راه‌اندازی اولیه

```bash
php artisan migrate --force
php artisan soorin:install
```

دستور `soorin:install` این کارها را می‌کند و **idempotent** است (اجرای دوباره
چیزی خراب نمی‌کند):

1. مجوزها و نقش‌ها را می‌سازد.
2. انبار پیش‌فرض («انبار مرکزی» و «مرجوعی و معیوب») و ارزهای دلار/یوان را می‌سازد.
3. **کاربر مدیر اولیه را می‌سازد** — نام، ایمیل و گذرواژه را از تو می‌پرسد.

می‌توانی بدون پرسش هم بسازی:

```bash
php artisan soorin:install --name="مدیر" --email="admin@example.com" --password="یک-گذرواژه-قوی"
```

> اگر بعداً گذرواژه را فراموش کردی، همین دستور را با همان ایمیل دوباره بزن؛
> گذرواژه را به‌روز می‌کند.

## ۶. لینک فایل‌ها و کش (اختیاری ولی توصیه‌شده)

```bash
php artisan storage:link
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

اگر بعداً `.env` را عوض کردی، حتماً `php artisan config:clear` را بزن.

## ۷. تنظیم وب‌سرور

- **DocumentRoot** باید به پوشهٔ **`public/`** اشاره کند (نه ریشهٔ پروژه).
- پوشه‌های `storage/` و `bootstrap/cache/` باید قابل‌نوشتن باشند
  (`chmod -R 775` روی لینوکس).
- اگر آپاچی است، فایل `public/.htaccess` کار rewrite را انجام می‌دهد
  (پیش‌فرض لاراول). اگر nginx است، تنظیم استاندارد لاراول را بگذار.

روی سرور خودت برای تست سریع می‌توانی به‌جای وب‌سرور از این استفاده کنی:

```bash
php artisan serve --host=0.0.0.0 --port=8001
```

## ۸. اولین ورود

آدرس پنل: `http://آدرس-شما/admin`
با **ایمیل و گذرواژه‌ای که در مرحله ۵ ساختی** وارد شو. همین کاربر مدیرِ کامل
است و می‌تواند بقیهٔ کاربران و دسترسی‌هایشان را از منوی «کاربران» بسازد.

---

## وارد کردن موجودی فعلی از فایل اکسل (اختیاری)

اگر فایل اکسل انبار داری:

```bash
php artisan inventory:import-anbar "مسیر/Anbar.xlsx"
```

پیش از اجرای واقعی یک بار با `--dry-run` گزارش را ببین. (نیازمند افزونهٔ `zip`.)

## پشتیبان‌گیری — و آن «پشتیبان خودکار پیش از بازیابی»

- فایل‌های پشتیبان در **`storage/app/backups/`** ذخیره می‌شوند و در صفحهٔ
  «پشتیبان‌گیری» فهرست می‌شوند.
- وقتی «بازیابی» می‌زنی، سامانه **قبل از هر کاری** یک پشتیبان از وضعیت فعلی
  می‌گیرد با نامی مثل `backup-۱۴۰۵-۰۵-۲۷_۱۴۳۰۰۰-ab3x.sql` و علتِ «پشتیبان
  خودکار پیش از بازیابی». این فایل هم در همان پوشه و هم در فهرست صفحهٔ
  پشتیبان‌گیری هست. اگر بازیابی خراب شد، از صفحهٔ «بازیابی» همین فایل را از
  فهرست «انتخاب از پشتیبان‌های موجود روی سرور» بردار و برگردان.

## هاست اشتراکی بدون SSH

اگر روی هاست SSH نداری:
1. کد را با `composer install` روی سیستم خودت آماده کن و همه را (با پوشهٔ
   `vendor/`) آپلود کن.
2. `.env` را دستی بساز/ویرایش کن (مرحله ۴).
3. مهاجرت و راه‌اندازی را نمی‌توانی با artisan بزنی؛ به‌جایش:
   - جدول‌ها: خروجی SQL مهاجرت را از یک نصب مشابه بگیر و در phpMyAdmin وارد کن،
     **یا** یک بار روی سیستم خودت `migrate` بزن و دیتابیس را export/import کن.
   - کاربر مدیر: ساده‌ترین راه این است که روی سیستم خودت `soorin:install` را
     بزنی و بعد کل دیتابیس را روی هاست وارد کنی.
   - DocumentRoot را روی `public/` تنظیم کن (در cPanel از «Domains» یا با
     یک `index.php` هدایت‌کننده).
