# نشانهٔ همگام‌سازیِ زبان‌ها (i18n sync marker)

> این فایل «نشانه»ای است که می‌گوید ترجمه‌ها تا کجا در همهٔ زبان‌ها همگام‌اند و از کجا
> به بعد فقط فارسی به‌روز شده است.

## قانون
- **مرزِ آخرین همگام‌سازیِ کامل: `v1.15.0`** — تا این نسخه، هر ۸ زبان
  (fa, en, ar, de, fr, it, ru, zh) دقیقاً کلیدهای یکسان داشتند.
- **از v1.15.0 به بعد:** کلیدهای تازهٔ رابط فقط به **`lang/fa/`** افزوده می‌شوند
  (فارسی = منبعِ حقیقت). زبان‌های دیگر عمداً عقب می‌مانند تا وقتی مالک بخواهد یک‌جا
  همگام شوند.
- تستِ `LocalizationTest::test_other_locales_have_no_keys_beyond_persian` فقط بررسی
  می‌کند زبان‌های دیگر کلیدِ **اضافه/غلط** نداشته باشند؛ عقب‌بودن اشکالی ندارد.

## وقتی خواستی زبان‌های دیگر را با فارسی همگام کنی
این دستور، به‌ازای هر زبان، **کلیدهایی که در فارسی هست ولی در آن زبان نیست** (یعنی همان
چیزهایی که باید ترجمه شوند) را فایل‌به‌فایل چاپ می‌کند:

```bash
php -r '
$flat=function($a,$p="") use (&$flat){$k=[];foreach($a as $key=>$v){$f=$p===""?$key:"$p.$key";$k=is_array($v)?array_merge($k,$flat($v,$f)):array_merge($k,[$f]);}return $k;};
foreach (glob("lang/fa/*.php") as $ff) { $name=basename($ff); $fa=$flat(require $ff);
  foreach (["en","ar","de","fr","it","ru","zh"] as $l) {
    $o=file_exists("lang/$l/$name") ? $flat(require "lang/$l/$name") : [];
    $missing=array_diff($fa,$o);
    if ($missing) echo "$l/$name: ".implode(", ",$missing)."\n";
  }
}'
```

پس از ترجمهٔ همهٔ موارد و رسیدن خروجی به خالی، **این فایل را به‌روز کن** (مرز را به نسخهٔ
جاری برسان) تا نشانه دقیق بماند.
